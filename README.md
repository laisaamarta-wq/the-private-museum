# The Private Museum

An immersive high jewellery exhibition website (concept by Marta Jakovleva).
Plain HTML, CSS and JavaScript; no build step. Pages are generated from `build.py`.

- `index.html` — the walk through seven salons
- `catalogue.html`, `objects/*.html` — catalogue and one page per piece
- `assets/` — architecture, jewellery, details, audio, fonts
